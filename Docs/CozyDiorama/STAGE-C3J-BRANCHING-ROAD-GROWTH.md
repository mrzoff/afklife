# Stage C-3J — ветвящийся рост дорожной сети

Ветка: `feature/cozy-diorama-stage-c3j-branching-road-growth` (от C-3I). Renderer, Save v8, лимиты роста,
ResidentPathGraph, стартовый участок и правила для хижин не менялись. Изменён только выбор кандидатов
`Clearing -> Path` в `SettlementSimulation`.

## Правила

1. **Продолжение сети, приоритет концам ветвей** — `BranchExtensionBonus`: клетка, примыкающая ровно к одной
   дороге со степенью <= 1, получает +10 к score; к дороге степени 2 — 0; к узлу степени >= 3 — -4.
2. **Замыкание 2x2 и петель отклоняется** — `IsBranchingPathAllowed`: если у кандидата >= 2 дорожных соседей,
   он допустим только если они принадлежат разным компонентам (мост между компонентами, нужен для связности).
   Иначе отклоняется.
3. **Параллельные полосы запрещены** — кандидат с одним соседом отклоняется, если в каком-либо направлении
   через одну свободную клетку лежит дорога (`!road(c+d) && road(c+2d)`).
4. **T и X сохраняются** — степень узла растёт за счёт новых веток на конце/боку, правило 2 не мешает ветке
   присоединиться к одной клетке сети.
5. C-3G (`IsRoadJunctionCell`, мосты/точки сочленения, `IsProtectedRoadCell`) и правило C-3H (Path только
   рядом с cardinal-дорогой) без изменений.
6. Проверка повторяется в `TryApplyUpgrade`, так что кандидат из устаревшего списка не пройдёт.
